# Utvecklingsgrunder

## Vad jag har lärt mig

Den här sidan sammanfattar mina viktigaste lärdomar under kursveckan. Exemplen är till för nya studenter som vill komma igång.

## 1. Git och GitHub

Git används för att spara och följa ändringar i projekt. GitHub används för att lagra projekt online.

Exempel på vanliga kommandon:

```bash
git status "Kontrollerar ändringar"
git add "Förbereder ändringr"
git commit -m "Sparar ändringar"
git push origin main "Skickar ändringar till GitHub"
git fetch origin "Kontrollerar om det finns nya ändringar på GitHub"
```

**Tips:** Använd `git status` för att kontrollera läget innan du gör ändringar.

## 2. Markdown

Markdown används för att formatera text, till exempel i README-filer.

Exempel:

```markdown
# Stor rubrik
## Mindre rubrik
**Fet text**
*Lutande text*

- Första punkten
- Andra punkten
```

**Tips:** Markdown gör dokumentationen enkel att läsa.

## 3. HTML och CSS

HTML bygger upp innehållet på en webbsida. CSS bestämmer hur sidan ser ut.

HTML-exempel:

```html
<!DOCTYPE html>
<html lang="sv">
<head>
    <meta charset="UTF-8">
    <title>Min första webbsida - version 2</title>
</head>
<body>
    <h1>Hej världen!</h1>
    <p>Det här är min första webbsida.</p>
</body>
</html>
```

CSS-exempel:

```css
h1 {
    color: blue;
    text-align: center;
}
```

**Tips:** HTML skapar strukturen och CSS skapar utseendet.

## 4. Visual Studio Code

Visual Studio Code (VS Code) är ett program för att skriva och redigera kod.

Några användbara funktioner:

- **Emmet:** Skapa HTML-struktur snabbt genom att skriva `!` och trycka Tab.
- **Live Server:** Visa webbsidan direkt i webbläsaren.
- **Lorem Ipsum:** Skapa exempeltext snabbt med `p>lorem` och Tab.

**Tips:** Använd tillägg för att göra arbetet enklare och snabbare.
